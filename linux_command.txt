

##System and process management

ps aux               --> list all running processes
top / htop           --> monitor CPU, memory, running processes
free -h              --> check memory usage
df -h                --> check disk usage
du -sh <folder>      --> check folder size
kill -9 <pid>        --> force kill a process

systemctl status <service>   --> check service status (e.g. nginx, docker)
systemctl start/stop/restart <service>
journalctl -u <service>      --> view service logs



##Networking (essential for cloud/servers)

ping <host>         --> check connectivity
curl -I <url>       --> check HTTP response headers
netstat -tulnp      --> list open ports and listening services
ss -tulnp           --> modern replacement for netstat

ssh user@host         --> connect to a remote server
scp file user@host:/path   --> copy files over SSH
ip a                  --> check network interfaces/IP


##File & permission management

chmod 755 file        --> change permissions
chown user:group file --> change ownership
ls -la                --> list files with permissions
find / -name "file"   --> search for files
grep -r "text" .      --> search text inside files
tail -f logfile.log   --> live-follow a log file (great for debugging deployed apps)


##Package & environment management

apt update && apt upgrade     --> update packages (Debian/Ubuntu — common on cloud VMs)
apt install <package>
which <command>               --> find path of a command
env                           --> view environment variables
export VAR=value              --> set environment variable (used a lot in cloud configs)
